# Visual Itinerary UI System

Source guidance: the project-local UI/UX Pro Max skill (`2.15.0`) and its
travel-itinerary design-system search. This document adapts that guidance to
the itinerary page and separate graph-inspection page. ADR 0006 records the
user's removal of the route map.

## Itinerary page

- Keep the trip form, validated plan and chat in one readable flow. Number
  places in the same chronological order used for chat edits.
- Use clear headings and text labels for schedule, estimated visit/travel time,
  opening-hour verification and source references.
- Show a Wikimedia Commons place photo only with creator, license and a link to
  its source page. Otherwise show a short unavailable message.
- Limit photo lookups to the first 12 stops; all other stops retain their text
  itinerary and planning sources.
- Do not render a geographic route map, coordinate links or a car marker.
  Photo enrichment stays separate from plan validation and session state.

## Graph-inspection page

- Show the PNG generated by `TravelPlannerService.get_graph_image()` with
  accessible alternative text and a PNG download. Use the local SVG topology
  only when the Mermaid PNG renderer is unavailable.
- Identify Coordinator, Planner, validation, repair and terminal nodes; use
  text and line style as well as color to distinguish conditional edges.
- Provide the underlying node and edge list for detailed inspection. Viewing
  this page does not run a planning turn or change the current itinerary.
