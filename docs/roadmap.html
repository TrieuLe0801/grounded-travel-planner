Nhịp làm việc

Mỗi phiên 90–120 phút, luôn kết thúc bằng bằng chứng và ghi chú.

01
Learn → Spike

Đọc một khái niệm khoảng 20 phút, rồi tạo ví dụ nhỏ để kiểm chứng mental model.

02
Build → Verify

Tích hợp một lát dọc nhỏ; chạy test, trace hoặc evaluation trước khi mở rộng.

03
Note → Decide

Ghi kết quả, gotcha, assumption và ADR. Chỉ giữ tính năng khi experiment cho thấy giá trị.

Kiến trúc mục tiêu

Graph cha sở hữu state và memory; subgraphs chỉ xử lý nhiệm vụ chuyên biệt.

User → load preferences → normalize request → requirements complete?
                                         ├─ no → interrupt(CLARIFY) ─┐
                                         └─ yes                      │
                                              ↓                      │
                               call LangChain travel tools           │
                                              ↓                      │
                    ┌─────────────────────────┴───────────────────┐  │
                    │ single planner | specialist LangGraph nodes │  │
                    └─────────────────────────┬───────────────────┘  │
                                              ↓                      │
                                aggregate structured results         │
                                              ↓                      │
                            build itinerary → deterministic checks ←─┘
                                              ↓
             PLAN_READY | RESEARCH_INCOMPLETE | NEEDS_USER_DECISION
                                              ↓
                            optional memory proposal → END

Ba lớp trạng thái và dữ liệu

Không đồng nhất thread state, long-term preference và kết quả từ external tools.

Short-term state

Theo thread_id: trip request, tool results, draft và workflow state. Lưu bằng LangGraph checkpointer.

Long-term memory

Theo user qua nhiều thread: home airport, pace và preferences đã xác nhận. Lưu bằng LangGraph Store.

External tool data

Flight/lodging fixtures, places, weather và route results qua LangChain tools, luôn có provenance và freshness.

Lộ trình chi tiết

Checklist và ghi chú tự lưu; xuất JSON để sao lưu hoặc chuyển máy.

Không có phiên phù hợp với bộ lọc.
