City sightseeing planner

LangGraph runtime with Coordinator routing and bounded session summaries, Planner grounded proposals, and Chat responses with optional search through one shared Tavily graph node.

Models

OpenAI defaults: Coordinator gpt-5.5, Planner gpt-5.4-mini, Chat gpt-4.1; opt-in local ollama by role

State

Session-only plan, 12-message transcript and 1,200-character handoff summary

Bounds

8 graph · 2 search · 1 repair
